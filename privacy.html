HypeClipper privacy policy

Last updated November 18, 2026

HypeClipper is a private tool used only by the owner of the HypeClipped YouTube channel to post clips to that channel. It is not offered to the public, and nobody else signs in to it.

What HypeClipper accesses

When the channel owner signs in with Google, HypeClipper asks for permission to:

  • upload videos to the HypeClipped channel,
  • read the channel's own videos and their view counts and privacy status,
  • add the channel's videos to the channel's own playlists.

It does not read email, contacts, files or any other Google data, and it does not access any other person's Google account.

How the data is used and stored

The sign-in token Google issues is stored only on the channel owner's own computer, readable only by that user, and is used only to post approved clips, check how they are doing, and keep the channel's playlists up to date. Video view counts are kept on the same computer to decide which clips to post. Nothing is sold, shared with anyone, or used for advertising.

Live stream chat

To find big moments, HypeClipper counts how fast public live stream chat is moving and which reaction words appear. Chat usernames are never stored.

Removing access

The channel owner can remove HypeClipper's access at any time at myaccount.google.com/permissions. Deleting the token file on the owner's computer has the same effect.

Google API Services

HypeClipper's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. It uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Contact

Questions about this policy can be sent through the HypeClipped channel.
